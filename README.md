# parsatabatabaii.github.io

Personal portfolio website for SeyyedParsa Tabatabaii — Software Engineer, AI Specialist & VoIP Expert.

## 🚀 Setup

1. Add your profile photo as `photo.jpg` in the root folder (ideally a portrait, 400×500px or similar ratio).
2. Push all files to your `parsatabatabaii.github.io` repository on GitHub.
3. Go to **Settings → Pages** and set the source to `main` branch, `/root`.
4. Your site will be live at `https://parsatabatabaii.github.io`

## 📁 Files

```
parsatabatabaii.github.io/
├── index.html   — Main page
├── style.css    — All styles
├── script.js    — Scroll animations & nav
├── photo.jpg    — Your profile photo (add this yourself)
└── README.md    — This file
```

## 🎨 Customization

- Colors: Edit CSS variables at the top of `style.css`
- Content: All text is in `index.html`
- Photo: Replace `photo.jpg` with your preferred photo
